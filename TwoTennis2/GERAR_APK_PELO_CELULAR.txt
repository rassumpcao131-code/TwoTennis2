TWOTENNIS2 - GERAR O APK USANDO SOMENTE O CELULAR
=================================================

O projeto ja possui uma compilacao automatica dentro de:
.github/workflows/gerar-apk.yml

O GitHub ira usar Java 17, Android API 36 e o Gradle do proprio projeto.
Ele gerara um APK de teste assinado e pronto para instalar.

PASSO 1 - COLOCAR O PROJETO NO GITHUB
--------------------------------------
1. Crie uma conta em https://github.com, caso ainda nao tenha.
2. Crie um repositorio novo chamado TwoTennis2.
3. Extraia o ZIP deste projeto no celular.
4. Envie o CONTEUDO da pasta TwoTennis2 para a raiz do repositorio.

IMPORTANTE:
- A pasta .github tambem precisa ser enviada.
- Ative "Mostrar arquivos ocultos" no gerenciador de arquivos para enxerga-la.
- build.gradle.kts, settings.gradle.kts, gradlew e a pasta app devem aparecer
  diretamente na pagina inicial do repositorio.
- Nao deixe tudo dentro de uma segunda pasta TwoTennis2.

FORMA MAIS CONFIAVEL PELO CELULAR - TERMUX
------------------------------------------
Se o navegador nao permitir enviar as pastas corretamente, use o Termux.
Instale o Termux por uma fonte oficial, abra-o e execute um comando por vez:

pkg update
pkg install git gh unzip
termux-setup-storage

Aceite a permissao de arquivos. Depois, supondo que o ZIP esteja em Downloads:

cd ~/storage/downloads
unzip TwoTennis2_APK_AUTOMATICO.zip -d ~/twotennis-github
cd ~/twotennis-github/TwoTennis2
git init
git config user.name "Seu nome"
git config user.email "seu-email@example.com"
git add .
git commit -m "TwoTennis2 pronto para gerar APK"
git branch -M main
gh auth login

No login, escolha GitHub.com, HTTPS e a opcao de entrar pelo navegador.
Depois de autorizar sua conta, volte ao Termux e execute:

gh repo create TwoTennis2 --private --source=. --remote=origin --push

Esse comando cria um repositorio privado e envia o projeto completo, incluindo
a pasta oculta .github. A compilacao comecara automaticamente depois do envio.

PASSO 2 - INICIAR A COMPILACAO
------------------------------
1. Abra o repositorio no navegador do celular.
2. Entre na aba Actions.
3. Abra "Gerar APK do TwoTennis2".
4. Toque em "Run workflow" e depois no botao verde "Run workflow".
5. Aguarde a tarefa ficar verde. Na primeira vez pode demorar alguns minutos.

A compilacao tambem comeca automaticamente quando arquivos sao enviados para
as branches main ou master.

PASSO 3 - BAIXAR O APK
----------------------
1. Na aba Actions, abra a compilacao concluida.
2. Role a pagina ate a secao Artifacts.
3. Toque em "TwoTennis2-APK".
4. O GitHub baixara um ZIP pequeno.
5. Extraia esse ZIP e instale o arquivo app-debug.apk.

Se o Android bloquear a instalacao, permita temporariamente a opcao
"Instalar aplicativos desconhecidos" para o navegador ou gerenciador de
arquivos usado. Desative a permissao novamente depois de instalar.

SE O BOTAO RUN WORKFLOW NAO APARECER
------------------------------------
- Confirme que gerar-apk.yml esta em .github/workflows/.
- Confirme que o repositorio esta na branch main ou master.
- Abra Actions e aceite habilitar workflows, se o GitHub solicitar.

ONDE O APK E GERADO
-------------------
app/build/outputs/apk/debug/app-debug.apk

Esse e um APK de DEBUG, ideal para testar e instalar no seu proprio celular.
Para publicar na Play Store futuramente sera necessario gerar uma versao
RELEASE assinada com uma chave privada.
